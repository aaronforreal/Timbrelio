disappear. After about half a minute, the moderator asked which control might
change the tracks being shown. Cat then found the Genres filter, selected Rock,
opened a track, read its ID correctly, and reset the map.

them to describe only what they could see. Cat said the UMAP map had several tighter
groups while PCA looked more evenly spread out, then returned to PCA.
